```txt

Model    : YOLO-based object detection
Logic    : Left / Right inspection zones
Output   : OK / NG + vehicle-linked logs
Stack    : Python • PyTorch • OpenCV • YOLO
System   : PLC-oriented industrial workflow
```

**Highlights:** live inference, production-style status UI, camera pipeline handling, inspection logging, and PLC integration work.

SELECT TASK
      ↓
CONFIGURE MODEL
      ↓
RUN / ANALYZE
      ↓
VIEW RESULTS

Built to make ML workflows less intimidating and easier to use, with **Supabase**, authentication, model workflows and rate-limiting in the architecture.
